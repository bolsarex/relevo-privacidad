# Relevo: privacidad y soporte

Página pública de política de privacidad y soporte de la app Relevo, para la
ficha de App Store y Google Play. Es una sola página estática (`index.html`),
en español e inglés.

Se publica con GitHub Pages: `https://bolsarex.github.io/relevo-privacidad/`.

El original vive en el repo de la app (`docs/privacidad/`); si cambia lo que la
app guarda, hay que actualizar ambos.
